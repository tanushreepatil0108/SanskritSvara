💡 Application Logic

1. Sound classification

Input character → search sounds.json → identify vowel/consonant → show place, voicing, aspiration and varga.

2. Word analysis

Input word → search words.json → return meaning, root, prefix, suffix, tense, person, number and formation.

3. Phonetic engine

The stored phonetic units are rendered separately, e.g. ग + च् + छ + ति. Clicking a unit opens its sound analysis.

4. Pronunciation

The browser Speech Synthesis API is used with a safe voice fallback. The app also shows available voices for troubleshooting.

5. Language technology

The same structured data can later be connected to NLP, speech recognition, morphology rules and a mobile application.

6. Digital preservation

Sanskrit lexical and phonetic information is stored in structured Unicode JSON, making it searchable and reusable by software.
